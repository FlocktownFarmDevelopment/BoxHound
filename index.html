How to Use BoxHound

Finding Add-On Items

1
Upload your labels

Export a "Labels" CSV report from Farmigo and upload it using the file picker or drag & drop.

2
Search for an item

Start typing an add-on item name in the search bar. Select it from the autocomplete dropdown, or click a quick pick chip.

3
Check the boxes

BoxHound shows every member box that contains that item, sorted by route and box number so you can pack in order.

4
Pin & export

Click Pin to save an item's box list. Search and pin as many items as you need, then click Export CSV to download a checklist.

Blank Labels

!

Click the green Blank Labels button in the header to see all members whose labels have no produce swaps or add-on store items — just a share size and any subscription shares (eggs, milk, bread). Click the button again to dismiss the list.

Keyboard shortcuts: Cmd+K to focus search • Arrow keys to navigate suggestions • Enter to select • Escape to clear
